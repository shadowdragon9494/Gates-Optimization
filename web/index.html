03 / AI METHOD

Turn a timetable
into a search space.

Google OR-Tools CP-SAT assigns every aircraft to an eligible gate. Overlapping flight pairs create conflict variables; the objective weights each conflict above a gate change.

MINIMIZE301 × conflicts + gate changesWith 300 aircraft, one fewer conflict always outweighs any possible reduction in gate changes.

A feasible solution is not a proof of global optimality. Solver status and bounds stay visible in the outcome comparison.
